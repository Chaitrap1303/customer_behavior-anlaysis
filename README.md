# 📊 Data Analytics Project

## Overview

This project demonstrates an end-to-end Data Analytics workflow, covering data loading, cleaning, analysis, visualization, and reporting. The project uses Python for data processing and Exploratory Data Analysis (EDA), SQL for database querying, Power BI for dashboard development, and Gamma for presentation creation.

The goal is to transform raw data into actionable insights that support data-driven decision-making.

---

## Dataset

The dataset contains structured business/customer data used for analysis and reporting.

### Objectives
- Load and preprocess data
- Perform Exploratory Data Analysis (EDA)
- Execute SQL queries for business insights
- Build an interactive Power BI dashboard
- Present findings through a professional presentation

## How to Run

### Prerequisites

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy
```

### Steps

1. Clone the repository:

```bash
git clone https://github.com/your-username/data-analytics-project.git
```

2. Navigate to the project directory:

```bash
cd data-analytics-project
```

3. Run the analysis script:

```bash
python main.py
```

Or open the notebook:

```bash
jupyter notebook
```

4. Execute the SQL queries in PostgreSQL, MySQL, or SQL Server.

5. Open Power BI and connect to the database.

6. Refresh the dashboard to view updated insights.

7. Open the Gamma presentation to review the project findings.
